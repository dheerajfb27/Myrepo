# SkyScape Weather Widget — fresh rebuild

Clean native Android app for Pixel 10 with a resizable home-screen weather widget, Bengaluru current weather, five-day forecast, and visible API diagnostics.

- Kotlin native RemoteViews widget
- Open-Meteo endpoint (no API key)
- Horizontal and vertical widget resizing
- Tap widget or app button to refresh
- API state shown if a fetch fails

Build with Android Studio or the GitHub Actions workflow.
